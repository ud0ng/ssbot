# ssbot — 마스토돈 커뮤니티 자동봇

구글 스프레드시트로 운영하는 마스토돈 자동봇입니다. 운영진이 시트만 고치면 봇의 답변·상점·조사·예약 툿·스토리가 바로 바뀝니다.

- **기본**: 주사위, 랜덤, 운세, 키워드 답변(이름·주사위·랜덤 치환, 이미지 첨부)
- **상점·스탯**: 소지금, 가방, 상점, 구매, 아이템 설명·소모·사용(스탯 변화)
- **옵션**: 양도, 출석, 툿 수 → 재화 자동 반영, 랜덤박스
- **자동조사**: 장소 목록, 진입, 조사(아이템 획득·스탯 변화), 하루 조사 횟수 제한
- **예약 툿**, **스토리 자동 진행** (여러 봇 계정)

---

## 명령어

툿에 봇 계정을 멘션하고 `[명령어]`를 적습니다. 예: `@BOT 오늘 운세는? [운세]`

| 명령어 | 설명 |
|---|---|
| `[도움말]` | 도움말 시트 내용 |
| `[1d100]` `[3d6+5]` | 주사위 |
| `[랜덤/A, B, C]` | 하나 고르기 |
| `[운세]` | 오늘의 운세 (같은 날은 같은 결과) |
| `[키워드]` | 키워드 시트에 적은 답변 (여러 줄이면 랜덤) |
| `[가방]` / `[상태 확인]` | 소지금·소지품 / + 스탯 |
| `[상점]` `[설명/템]` `[구매/템]` `[구매/템/수량]` | 상점 |
| `[소모/템]` | 아이템 1개 없애기 (스탯 변화 없음) |
| `[사용/템]` | 아이템 사용 (상점 시트의 스탯 변화 적용) |
| `[양도/3코인/캐릭터명]` `[양도/사과: 2/캐릭터명]` | 재화·아이템 주기 |
| `[출석]` | 하루 한 번 재화 받기 |
| `[랜덤박스]` `[랜덤박스/박스명]` | 박스 목록 / 열기 |
| `[장소 목록]` `[진입/장소]` `[조사/포인트]` | 조사 |

**운영진 명령어** (`.env` 의 `ADMIN_IDS`)

| 명령어 | 설명 |
|---|---|
| `[캐시 리셋]` | 시트 수정 내용을 바로 반영 |
| `[소지금 추가/10/겐지, 디바]` `[소지금 차감/10/전원]` | 소지금 |
| `[아이템 추가/사과: 2, 포도: 3/겐지]` `[아이템 차감/…]` | 소지품 |
| `[체력 변경/+3/겐지]` `[정신력 변경/-1d6/전원]` | 스탯 (관리 시트에 있는 스탯) |
| `[스진/워크시트명]` `[스진 중지]` | STORY 계정에 DM — 스토리 진행 |

답장 공개 범위는 요청과 같습니다 (DM → DM).

## 시트

네 시트는 각각 따로 만들고 `.env` 에 ID 를 넣습니다. 비워 둔 시트의 기능은 꺼집니다.
아래 예시 시트를 열어 **파일 → 사본 만들기**로 시작하면 편합니다.

- [기본 & 상점 & 스탯 시트](https://docs.google.com/spreadsheets/d/1iTqRwJChqTCpfpMaleLEt2i1h2MTroyWAbNktZF8KjA/edit?usp=sharing)
- [예약 툿 시트](https://docs.google.com/spreadsheets/d/1ui6iVgG-nDLF2RDVd50bz2jVeBU9JRp3f5oCx3a4eQE/edit?usp=sharing)
- [스토리 자동진행 시트](https://docs.google.com/spreadsheets/d/1K0mXU2NOQ71HF9Mo6Zs_cFHlpDPeRFm_N8v7Pts58cY/edit?usp=sharing)
- [조사 시트](https://docs.google.com/spreadsheets/d/1kccCpDwSaQyaNeUxmCfyIrUNM9taJDeyfQfXTMcBQ24/edit?usp=sharing)

시트 ID 는 주소의 `/d/` 와 `/edit` 사이 문자열입니다.

### 기본 시트 (MAIN_SHEET_ID)

열은 **헤더 이름**으로 찾으므로 순서가 달라도, 빈 열이 끼어 있어도 됩니다.

| 워크시트 | 헤더 | 비고 |
|---|---|---|
| 도움말 | 명령어 \| 설명 | `[`로 시작하는 줄만 출력 |
| 명단 | 이름 \| 아이디 | `{시전자}` 이름 (상점 없는 기본 타입) |
| 관리 | 이름 \| 아이디 \| 소지금 \| 소지품 \| 체력 \| 정신력 … | 소지품 오른쪽 열은 모두 스탯. 소지품은 `사과: 2, 반지: 1` |
| 상점 | 아이템명 \| 가격 \| 설명 \| 스탯 \| 수치 | 가격이 숫자가 아니면 비매품. 스탯 `사용 불가`. 수치는 `5`, `-20`, `1d10`, `-(1d6+3)` |
| 운세 | 문구 | |
| 키워드 | 키워드 \| 답변 \| (이미지) | 이미지 칸에 이미지 주소(https://…)를 적으면 첨부 |
| 랜덤박스 | 박스명 \| 가격 \| 아이템 \| 수량 \| 확률 | 박스명이 같은 줄끼리 한 박스. 가격은 첫 줄에. 가방에 박스명 아이템이 있으면 그걸 쓰고, 없으면 가격만큼 재화를 씀. 확률은 가중치(숫자) |

**치환** (키워드 답변·진입/조사 문구·예약 툿·스토리)

| 쓰는 법 | 결과 |
|---|---|
| `{시전자}` | 보낸 사람 이름 (명단/관리 시트, 없으면 표시 이름) |
| `{1d100}` `{5d5+5}` | 주사위 |
| `{랜덤: 송어, 광어}` | 하나 고르기 |
| `{은는}` `{이가}` `{을를}` `{과와}` `{아야}` `{으로로}` | 앞 글자 받침에 맞는 조사 |

예: `{시전자}{이가} {랜덤: 송어, 광어}{을를} 낚았다!` → `엘레나가 광어를 낚았다!`

### 예약 툿 시트 (RESERVATION_SHEET_ID)

워크시트 `관리`: **날짜 \| 시간 \| 계정 \| 범위 \| 문구**
- 날짜 `08/01` 또는 `2026-08-01`, 시간 `22:01` (한국 시간)
- 계정: `.env` 의 `ACCOUNT_이름` (NOTICE, STORY, SYSTEM …)
- 범위: 일반 / 팔로워 / 디엠. 디엠은 문구에 `@아이디`를 적습니다.
- `@STORY [스진/3일차 파트1]` 를 NOTICE 로 디엠 예약하면 그 시간에 스토리가 시작됩니다.

### 스토리 시트 (STORY_SHEET_ID)

워크시트 하나가 한 파트(이름 = `[스진/이름]`): **계정 \| 간격 \| 문구** — 간격은 그 줄을 올리기 전에 기다릴 초.

### 조사 시트 (INVESTIGATION_SHEET_ID)

- `진입`: **장소명 \| 진입 시 문구 \| 현재 진입 가능** (가능/불가능). 같은 장소를 여러 줄 적으면 랜덤.
- 장소마다 워크시트(이름 = 장소명): **조사 포인트 \| 조사 시 문구 \| 획득 아이템 \| 변동 스탯**
  예: 획득 아이템 `기념주화: 3`, 변동 스탯 `체력: -3, 행운: +1d3` (관리 시트에 반영)

## 설치

### 1. 봇 계정과 토큰

마스토돈에 계정을 만듭니다: 명령어용 **BOT**, 그리고 쓰는 만큼 **STORY**, **SYSTEM**.
**NOTICE 는 공지 계정(manager)을 그대로 쓰는 것을 권장합니다** — 이 서버는 공개 툿을 막고
공지 계정의 조용한 공개만 전원에게 보여 주기 때문입니다. STORY·SYSTEM 의 툿은 팔로워에게만
보이므로 이용자들이 이 계정들을 팔로우하도록 안내하세요.

계정마다: 환경설정 → **개발** → **새 애플리케이션** → 이름 아무거나, 권한 `read` `write` 체크 → 저장 → **액세스 토큰** 복사.

### 2. 구글 서비스 계정

1. [Google Cloud 콘솔](https://console.cloud.google.com) → **API 및 서비스 → 라이브러리** → `Google Sheets API` **사용**
2. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정** → 이름 `ssbot` → 완료
3. 만든 서비스 계정 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 파일이 내려받아집니다 (= credentials.json)
4. 서비스 계정 이메일(`ssbot@….iam.gserviceaccount.com`)을 네 시트 모두에 **편집자로 공유**

### 3. 서버에 설치

```bash
curl -fsSL https://raw.githubusercontent.com/ud0ng/ssbot/main/install.sh | bash
```

질문에 답하고, 마지막 안내대로 `credentials.json` 을 넣은 뒤 `sudo systemctl restart ssbot`.

### 운영

| 할 일 | 명령 |
|---|---|
| 로그 보기 | `tail -f ~/ssbot/logs/bot.log` |
| 상태 | `sudo systemctl status ssbot` |
| 다시 시작 (`.env` 수정 후) | `sudo systemctl restart ssbot` |
| 최신 코드로 업데이트 | 설치 명령을 다시 실행 |

서버가 재부팅되어도 자동으로 켜집니다. 봇이 꺼져 있던 사이 받은 명령어는 다시 켜질 때 처리합니다.

## 개발

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest
```

`LOCAL_SHEETS_DIR=폴더` 를 주면 구글 시트 대신 `폴더/<시트>/<워크시트>.csv` 를 씁니다 (`tests/fixtures` 참고).
